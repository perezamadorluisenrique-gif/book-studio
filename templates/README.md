# Free template: Starter Book

A small, ready-to-write book for Book Studio. It uses only free features (the `classic` theme and the 6x9 trim).

1. Copy the `starter-book` folder into your vault.
2. Open `Starter Book.md` and fill in the title and author.
3. Write in the notes inside `Chapters`. Add a chapter by creating a note and linking it under `## Chapters`.
4. Run **Book Studio: Open studio** from the command palette and export the PDF or EPUB.

Writing a report or thesis instead? The [Section Numbering](https://github.com/perezamadorluisenrique-gif/section-numbering/tree/main/templates) repo has a free numbered report template.
