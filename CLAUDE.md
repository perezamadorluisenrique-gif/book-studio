# Orientation
- Before exploring, read `.claude/REPO_MAP.md` (files + top-level symbols; a SessionStart hook regenerates it, but repo hooks don't run in multi-repo sessions, so if it is missing run `python3 .claude/scripts/repo-map.py`) and use the `repo-map` skill; delegate multi-file searches to the Explore subagent.
- Read large files with `offset`/`limit`; use Grep to locate first.

# Compact instructions
When compacting, keep the list of modified files, the test commands run and their results, and open decisions.

# Facts
- Browser tests: `npm run build:web` then `npm run e2e` (Playwright + axe over `dist/web`; set `E2E_CHROMIUM` to a local Chromium, CI installs its own). App plan: `docs/APP-PLAN.md`.
- Pro keys come from the payment service and are validated once on Activate (`src/engine/license-online.ts`, a byte-identical copy of `obsidian-dev/tools/pro-license/license-online.ts`; settings in the generated `src/engine/pro-config.ts`, rewritten by `apply-config.mjs`, never by hand). `LicenseManager.activate(key, post)` in `src/app/license-manager.ts`; the Obsidian host's `post` uses `requestUrl`, the web's uses `fetch`. Offline `BS1.` Ed25519 keys (`license-offline.ts`, `node tools/license.mjs keygen|sign|verify`) stay as plan B and are inactive while `PUBLIC_KEYS` in `license-keys.ts` is empty. e2e builds set `PRO_LICENSE_TEST_API`; releases never do (`tests/release-build.test.ts`).
- Gates live in `src/engine/entitlements.ts`. Build flags (`esbuild.config.mjs`): `BOOK_STUDIO_EDITION=community` strips Pro, `BOOK_STUDIO_PRO_PREVIEW=1` unlocks it for demos.
- Merging a change to `manifest.json` publishes a release (`release.yml`). Pro stays unreleased: do not bump the version.
- KDP numbers (spine rate, barcode margin, spine text from 79 pages) are unverified against official templates.
- Web projects (A3): `src/project/` is pure (model, `projectToVault`, ops; `starter.ts` copies `templates/starter-book` and a test keeps them equal). `src/web/store.ts` is IndexedDB v2 (`handles`, `projects`); `src/web/projects.ts` is the "My books" screen. A4: `src/web/workspace.ts` is the writing screen (3 columns, tabs at ≤900 px; the Studio moves into its third column), with `chapters.ts` (list, drag and Alt+↑/↓) and `editor.ts` (autosave 500 ms); pure `ops.move/reorder` and `edits.ts`. Never swap the book source while `Studio.refresh()` runs (`refreshStudio()` in `main.ts`). A5: `src/web/details.ts` is the "Book: details" form (opens from the chapter list and from Problems links to the book note); pure `src/project/details.ts` (front matter fields, ISBN and 7-keyword checks) and `cover-image.ts` (JPG/PNG cover kept as asset `cover.png|jpg`, `cover:` line). The form's theme/trim clear the preview bar's saved override (`layoutChanged` in `main.ts`). The e2e runs EPUBCheck when Java and `out/epubcheck-5.2.1` exist (`npm run epubcheck` fetches it).
