# Orientation
- Before exploring, read `.claude/REPO_MAP.md` (files + top-level symbols; a SessionStart hook regenerates it, but repo hooks don't run in multi-repo sessions, so if it is missing run `python3 .claude/scripts/repo-map.py`) and use the `repo-map` skill; delegate multi-file searches to the Explore subagent.
- Read large files with `offset`/`limit`; use Grep to locate first.

# Compact instructions
When compacting, keep the list of modified files, the test commands run and their results, and open decisions.

# Facts
- Typography bench: `npm run quality` prints defect counts for 5 books; `npm run quality -- --write` lowers `tests/quality-baseline.json` (counts may only go down). Golden pages in `tests/golden/` (regenerate with `npx vitest run tests/golden.test.ts -u` only when a change moves lines on purpose).
- Page builder (`src/engine/layout/paginate.ts`): with `balance` it searches the cheapest way through a chapter, a facing pair at a time (costs at the top of the file). A pair may run one line long (`maxLong`, computed in `layout/index.ts` from the foot margin) and a `VSpace` with `stretch` may grow; `PageStats.long` records it and the folio at the foot moves down a line on those pages.
- Free KDP tools: `site/tools/` (see `docs/web-launch/FACTS.md`, last section). The only script on the site is `tools/tools.js`, on the tool pages; their figures fixture must be re-read from KDP every 180 days (a test enforces it).
- Browser tests: `npm run build:web` then `npm run e2e` (Playwright + axe over `dist/web`; set `E2E_CHROMIUM` to a local Chromium, CI installs its own). App plan: `docs/APP-PLAN.md`.
- This repo is the free edition only. Book Studio Pro is a private overlay (`obsidian-dev/book-studio-pro/`, laid over a clone with its `overlay.mjs`) that replaces these public stubs with the real modules: `src/edition.ts` (`PRO_INCLUDED`), `src/engine/{license-online,pro-config,editions,index-terms,a11y-report,themes-pro}.ts`, `src/engine/cover/templates-pro.ts`, `src/app/{license-manager,license-panel}.ts`. Keep each stub's exports a subset of the real module's (the overlay's test checks), and gate Pro-only tests with `describe.runIf(PRO_INCLUDED)` so the overlay still runs them. Never add Pro code here.
- Gates live in `src/engine/entitlements.ts`. Build flags (`esbuild.config.mjs`): a tree without the overlay always builds the free edition; with it, `BOOK_STUDIO_EDITION=community` strips Pro and `BOOK_STUDIO_PRO_PREVIEW=1` unlocks it for demos.
- Merging a change to `manifest.json` publishes a release (`release.yml`). Pro stays unreleased: do not bump the version.
- KDP numbers (spine rate, barcode margin, spine text from 79 pages) are unverified against official templates.
- Web projects (A3): `src/project/` is pure (model, `projectToVault`, ops; `starter.ts` copies `templates/starter-book` and a test keeps them equal). `src/web/store.ts` is IndexedDB v2 (`handles`, `projects`); `src/web/projects.ts` is the "My books" screen. A4: `src/web/workspace.ts` is the writing screen (3 columns, tabs at ≤900 px; the Studio moves into its third column), with `chapters.ts` (list, drag and Alt+↑/↓) and `editor.ts` (autosave 500 ms); pure `move`/`reorder` in `ops.ts` and `edits.ts`. Never swap the book source while `Studio.refresh()` runs (`refreshStudio()` in `main.ts`). A5: `src/web/details.ts` is the "Book: details" form (opens from the chapter list and from Problems links to the book note); pure `src/project/details.ts` (front matter fields, ISBN and 7-keyword checks) and `cover-image.ts` (JPG/PNG cover kept as asset `cover.png|jpg`, `cover:` line). The form's theme/trim clear the preview bar's saved override (`layoutChanged` in `main.ts`). The e2e runs EPUBCheck when Java and `out/epubcheck-5.2.1` exist (`npm run epubcheck` fetches it).
- Import and publishing (C): `src/project/import-text.ts` (splits `.md`/`.txt` into chapters; also builds the project), `import-docx.ts` (zip + XML parser given by the caller; browser `DOMParser`, tests use `@xmldom/xmldom` via `tests/docx-helper.ts`; loaded with a dynamic `import()`), `checklist.ts` (pure rules of the free publish checklist, drawn by `src/web/publish.ts`). Docx fixtures and snapshots: `tests/fixtures/docx/` (README lists what is not covered). `Studio.publishFacts()` gives the checklist the built book's numbers.
