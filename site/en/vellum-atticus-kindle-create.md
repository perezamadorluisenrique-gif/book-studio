If you want a book formatter that runs on Windows, you have four realistic choices: Atticus, Kindle Create, Book Studio, and Vellum if you have a Mac. Each fits a different author. This page is written by the makers of Book Studio, so read the limits of Book Studio as carefully as its strengths, then [open the app](app:) and judge for yourself.

## Where Vellum is better

Vellum is the benchmark for good-looking books. Its styles are polished, it offers 24 trim sizes, and the ebook and print versions stay in sync. If you own a Mac and want the best-looking result with the least effort, it is the strongest choice here. The cost is the price and the platform: Mac only. You pay when you generate files, not to try it. Source: [vellum.pub](https://vellum.pub/).

## Where Atticus is better

Atticus is a writing tool as well as a formatter. It has a built-in editor and templates, and it works on Windows, Mac, Linux and Chromebook. If you want to write and format in one place, with one purchase, it fits better than Book Studio, whose chapter editor is much simpler. It exports EPUB, print PDF and DOCX. It works offline after login but needs a connection to log in and export. Sources: [atticus.io](https://www.atticus.io/) and [Kindlepreneur's review](https://kindlepreneur.com/atticus-review/).

## Where Kindle Create is better

Kindle Create is free from Amazon and has a direct path to KDP. You import a DOC or DOCX manuscript, and it can prepare an ebook and a paperback from the same one. The output is a KPF file that you upload to KDP, and that file is only for publishing on KDP; see [KDP's help page](https://kdp.amazon.com/en_US/help/topic/GMUKXSTBCN6F2TGM). Tables, lists and footnotes cannot be edited inside it. If you write in Word and publish only on KDP, it may be all you need. Source: [amazon.com/kindlecreate](https://www.amazon.com/kindlecreate).

## Where Book Studio is better

- You write in Markdown, and you may already be doing that in Obsidian.
- It is free, with no watermark and no page or book limit in the web app.
- It makes a standard EPUB 3 and a print PDF, not a KPF locked to one store.
- Your manuscript is not uploaded and there is no account.
- It uses TeX's Knuth–Plass line breaking with hyphenation in six languages.

## Book Studio's limits

- No full word processor. The web app has a simple chapter editor (no comments, no track changes, no tables); you can also write in Obsidian or another Markdown editor, or import a Word file.
- No cover designer yet. It builds the full cover sheet at the size KDP expects and reports the spine width for your designer.
- Fewer themes than Vellum.
- The free plan prints every trim Book Studio supports (12 of KDP's 16) and includes the full cover and footnotes. Book Studio Pro adds genre themes, an index, box sets and the accessible-EPUB pack (one-time purchase): [see Pro](pro:).
- It is a young project by one developer.

## Which one to use

Use Vellum if you have a Mac and care most about design. Use Atticus if you want an editor and formatter together. Use Kindle Create if you write in Word and publish only on KDP. Use Book Studio if you write in Markdown or Word, want PDF and EPUB at no cost, or work on Windows or Linux.
